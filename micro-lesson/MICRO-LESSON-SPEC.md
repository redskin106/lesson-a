# Micro-Lesson Methodology Spec
## Confidence Ladder — Objects

*SkillsXLab / redskin106/lesson-a*
*Last updated: August 2026*
*Status: Design complete — ready for build*

---

## 1. What this is

A self-paced mobile micro-lesson for A0–A2 English learners — specifically refugee students aged 16–18 in Bangkok with mixed literacy levels and interrupted formal education. Each lesson teaches systematic object description through one object at a time.

This is not a quiz app. Not a drill tool. Not an AI tutor. It is a **sensory acquisition cycle** — a structured experience that encodes each concept through multiple neural pathways before asking the student to produce anything.

The tool serves the teacher-student relationship. It does not replace it.

---

## 2. The core principle

**The lesson moves at the speed of understanding, not the speed of content delivery.**

No timer. No countdown. No streak threatened by absence. The next button pulses gently when there is somewhere to go. The student goes there when they are ready. The lesson always waits.

For students who have experienced situations where being slow had real consequences, this is not a small design decision. It is the foundation of psychological safety — and psychological safety is the prerequisite for all learning.

---

## 3. The six observation questions

The lesson teaches students **how to look** before it teaches them what to say. Six questions the eye asks about any object, in the order perception naturally moves:

```
1. What is it?              → identity     → noun
2. How big / what shape?    → size + form  → size adjective
3. What colour?             → colour       → colour adjective
4. What is it made of?      → material     → material adjective
5. What is special about it?→ detail       → feature sentence
6. I want to know more      → curiosity    → question
```

These six questions ARE the six zones. Each zone teaches the student to ask one new question with their eyes — and then gives them the language to answer it.

This framework transfers to every object in every lesson, forever. It is the most valuable thing the lesson teaches.

---

## 4. The seven-step acquisition cycle

Every new concept goes through seven steps — each encoding it in a different neural system. The student experiences this as one smooth flow, not seven stages.

```
Step 1: ICON        → visual pattern recognition
Step 2: MIME        → motor / embodied memory
Step 3: IMAGE       → real-world semantic grounding
Step 4: AUDIO       → phonological memory
Step 5: WORD        → symbolic / linguistic memory
Step 6: RECORD      → active phonological production
Step 7: SKETCH      → motor + spatial + personal memory
```

### Step 1 — Icon
A symbol appears. No text. No language required. The brain pattern-matches to existing knowledge. The ↔ arrow already means size to a brain that has never seen English. This is the anchor everything else attaches to.

### Step 2 — Mime
A small animation shows a gesture in the corner. The student mirrors it or doesn't — never demanded. The body encodes the concept before the mind labels it. Embodied memory is stored separately from visual memory — if one fails under stress, the other holds.

**Gesture vocabulary for adjective order:**
- Size → both hands apart or close (calibrate to actual object)
- Material/texture → one hand rubbing the back of the other
- Colour → finger pointing to the eye
- Noun → both hands open, presenting

### Step 3 — Image
A real photograph of the concept in context. Not generic — always grounded in the object being described. The colour concept uses a photo of the actual bag. The size concept uses the actual bag next to something familiar. The student is always looking at what they are learning to describe.

### Step 4 — Audio
The word or sentence plays. The student has now had the concept through three channels — visual symbol, body memory, real-world image. The sound lands on prepared ground. It can be replayed as many times as needed. No limit. No consequence for replaying.

### Step 5 — Word
The English word fades in under the icon. Not first — last. The word is the name for something the student already fully understands. They do not need to decode it. They recognise it as a label.

### Step 6 — Record & Compare
*(Reused from vocab primer infrastructure)*

The student hears the model audio, records themselves, then hears both played back to back. Entirely private — no teacher sees the recording, no score is given, no feedback from the system. Just: *here is what it sounds like, here is what you sound like.* The student makes their own judgment.

Optional third mode for A1/A2 students: both tracks overlaid simultaneously — the student hears where their voice diverges from the model.

Tapping the record button is always optional. The lesson continues regardless. Over time, in a safe environment, most students choose to use it.

### Step 7 — Sketch
The lesson ends with a notebook prompt — not a written exercise but a drawing invitation. A blank canvas with tile icons arranged as border prompts. The student draws the object in the centre and annotates it with their own marks.

**This step happens on paper, not on the phone.**

The phone lesson is incomplete without the pencil. The sketch is not homework — it is the final step of the learning cycle. The drawing becomes a personal dictionary entry. Every object adds one page. Over a term the student builds a visual vocabulary that is entirely their own.

The Drawing Effect (research): drawing a concept produces significantly better recall than writing the word, reading it, or visualising it mentally. The physical act of making marks that represent meaning is one of the most powerful memory consolidation tools available.

## 5. The six zones

Each zone covers one observation question. Within each zone the seven-step cycle runs for the key concept, supported by 2–4 exercise types for variety and reinforcement.

### Zone 0 — Meet it
**Question: What is it?**
The object is hidden — shown as a silhouette only. The student cannot see it yet. The word appears first (audio + large text), then the image reveals when the student taps. Mystery is the engine. Curiosity pulls the student forward.

**Bricks:**
- Hear and say the word
- Connect word to image

### Zone 1 — What is it?
**Question: Can I name it?**
First complete sentence. Article + noun. The articles teaching moment lives here.

**Bricks:**
- *It's a bag.*
- Understanding of *a* (new) vs *the* (known)

**Teaching moment: Articles**
Visual world: deep indigo. A closed box with a question mark. Voice: *"There's a bag in here."* Box opens. Same voice: *"That's the bag."* Zero English explanation. The experience IS the lesson.

### Zone 2 — What does it look like?
**Question: Size, shape, colour?**
Three adjectives. The adjective order teaching moment lives here.

**Bricks:**
- *It's a big, flat, black bag.*
- Size → material → colour → noun (every time, in English)

**Teaching moment: Adjective order**
Visual world: dark green. Wrong order tiles assemble with jarring sound. Beat of silence. Tiles rearrange with satisfying mechanical snaps. Correct sentence plays resolved and warm. Rule chips appear: ↔ → ◻ → 🎨 → 📦. No text explanation. The animation IS the rule.

### Zone 3 — What makes it special?
**Question: What detail do I notice?**
Feature sentence. *It has a ___.*

**Bricks:**
- *It has a zip.*
- Understanding that objects have details worth naming

### Zone 3b — How does it feel?
**Question: What impression does it give me, and why?**
The because structure. The most personal zone — closest to the student's own experience.

**Bricks:**
- *It looks old because it's dirty.*
- Understanding of because as a bridge between feeling and reason

**Teaching moment: Because**
Visual world: deep rose. Two sentence halves float separately, both faded — something is missing. *Because* slides in between them like a bridge clicking into place. Both halves brighten. Sentence plays complete. Gesture: two fists apart, brought together with interlaced fingers. The concept is physical.

### Zone 4 — Questions
**Question: What do I want to know?**
The student learns to ask, not just describe. Two types: physical questions (Is it ___?) and behaviour questions (Does it ___? Can it ___?).

**Bricks:**
- *Is it big?*
- *Do you use it at school?*
- The student can ask when they don't know something

### Zone 5 — Comparison (stretch)
**Question: What is it like?**
Optional stretch zone. Unlocks silently. For students ready to go further.

**Bricks:**
- *It's like a suitcase.*
- Comparison as a description tool

### Zone 6 — The reveal
**Question: What have I built?**
The pyramid. The object image appears in full for the first time (was silhouetted in Zone 0). Tiers animate in one by one as audio plays. The student sees the complete description they have built, from simplest to most complex.

**Bricks:**
- Bronze: *It's a bag.*
- Silver: *It's a big, flat, black bag. It has a zip.*
- Gold: *It looks old because it's dirty.*

Then: notebook sketch prompt. Then: celebration.

## 6. Teaching moments

Three in total for the Objects lesson. Each is a completely different visual and sonic mode from the rest of the lesson.

### Design rules (non-negotiable)
1. **Zero English to understand it** — conveyed through animation, audio, and contrast alone
2. **Wrong version first** — contrast creates meaning; the more jarring the wrong version, the more satisfying the correction
3. **One concept only** — no secondary examples, no "also note that"; completeable in under 30 seconds of attention
4. **The student produces before leaving** — a gesture, a tap, a sound; the concept is active not passive

### Sound design
Four sounds, each with a distinct emotional job:

| Sound | Moment | Character |
|-------|--------|-----------|
| Arrival | Teaching moment begins | Warm, slightly ceremonial, 2–3 seconds, open/unresolved feeling |
| Ambient bed | Under the animation | Barely audible drone, different from lesson tone, signals "thinking pace" |
| Snap/click | Correct version lands | Single resolved note, satisfying, like a key turning |
| Celebration | Student taps "Got it" | Warm brief tone, slightly brighter than snap, brain says: stored |

All sounds sourced as real audio files. Stored at `micro-lesson/audio/ui/`. Not procedurally generated.

**Sources to search:** Freesound.org (CC0), Mixkit.co, Pixabay/music, ZapSplat.com
**Search terms:** "warm rise stinger", "discovery tone soft", "achievement melodic warm", "completion resolved chord"
**Avoid:** anything that sounds like a phone notification, game achievement, or quiz correct answer

## 7. Exercise types

Full module library available from shell. Use 2–4 types per zone for variety. Brain disengages when pattern becomes predictable. Never two consecutive screens that feel the same.

### Input exercises (student receives and recognises)
- Listen & Choose — audio → option
- Audio to image match — hear word → tap picture
- Picture & Word — image → word card match
- True/False with image
- Memory Pairs
- Colour pick — tap the correct colour swatch

### Production exercises (student constructs and outputs)
- Build-it — tile assembly (colour-coded, icon-first tiles)
- Fix-it — reorder/repair broken sentence
- Word Scramble — letter level
- Gap-fill — choose missing word
- Put in Order — sentence sequencing

### Bridge exercises (between recognition and production)
- Listen & Repeat prompt — say it along, no assessment, just the invitation
- Word Match — semantic connection
- Say It — open production with audio model

### Review exercises (consolidation)
- Quick recall — see image → build sentence from memory, no model shown
- Spaced return — same content 3 days later, no scaffolding

## 8. Tile system

Tiles are colour-coded by **role** not part of speech. The student learns what each colour means through use, not through explanation.

| Colour | Role | Icon | Example |
|--------|------|------|---------|
| Pink (#d81b60) | Size | ↔ | big, small, flat |
| Green (#388e3c) | Material/shape | ◻ | wooden, round, plastic |
| Red (#e53935) | Colour | ● (actual colour) | black, brown, red |
| Blue (#1565c0) | Noun | silhouette of object | bag, chair, bottle |
| Orange (#e65100) | Detail/feature | ✦ | zip, strap, handle |
| Dark blue (#311b92) | Reason | ↩ | because, so |
| Slate (#455a64) | Grammar words | — | It's, a, the, has |

### Tile reveal sequence (first encounter per tile type)
1. Icon only — no text, student looks
2. Word fades in below icon — after a beat
3. Optional: multiple choice images unfurl — "which of these is small?"
4. Correct tap — tile settles into final compact form, snap sound
5. Tile is now "learned" — stable, ready to use in build exercises

## 9. Self-pacing design

**The continue button:**
- Always present but never demanding
- Pulses gently after a natural pause — warm gold colour, soft heartbeat rhythm
- No countdown, no shrinking, no urgency
- Student taps when ready

**Natural stopping points:**
Every zone ends with a complete small thing. A student who stops after Zone 2 leaves with *It's a big, flat, black bag* — a real sentence they own. A student who reaches Zone 6 leaves with more. Both are valid. The lesson never punishes an early exit.

**Replay:**
Any audio clip can be replayed unlimited times. No limit. No consequence. No flag. A student who replays eight times is working hard — that's valuable signal for the teacher view.

## 10. Student tracking

Quiet engagement signals only. Invisible to student. No performance data.

**What is tracked:**
- Session opens + timestamps
- Zone depth reached per session
- Dwell time per screen
- Audio replay count per clip
- Record button attempts (not the recordings)
- Return visits to completed lessons

**What is NOT tracked:**
- Correct/incorrect answers
- Score or performance rating
- Speed through exercises

**Teacher view:**
Simple HTML page reading a JSON file in the repo. Per student, per lesson:
```
Davit — Bag lesson
Opened: 3 times | Last: yesterday, 22 min
Reached: Zone 5 | Record attempts: 4
Audio replays: 8 (model sentence, Zone 2)
```

**Student identification:**
Simple code assigned by teacher — not their name in the system. Privacy by default.

**The metric that matters most:**
Did they open it when the teacher wasn't in the room? Voluntary return is the signal that the tool has become theirs.

## 11. Home screen / progression

**Object progression:**
Objects unlock sequentially. Completing one object unlocks the next. A student cannot skip ahead — the language builds on itself.

Current object list (Level 1):
1. Bag 🎒 ← start here
2. Chair 🪑
3. Bottle 🧴
4. Phone 📱
5. Umbrella ☂️

**Spaced repetition:**
3 days after completing an object, a warm banner appears: *"Time to revisit — Bag. Quick 2-min check."* Same content, no scaffolding, pure recall. Not a threat. An invitation.

**Streak:**
Quiet record of visit days. No penalty for missing. No fire emoji threatening to go out. Just: *you've been here four times this week. that's real.*

**Can Do badges:**
One per zone completed. Named by what the student can now do, not by what they studied:
- Named it 🎒
- Described it 🎨
- Asked about it ❓
- Compared it 🔍
- Gold level 🏆

## 12. Games layer (planned, not built)

Separate Play tab. Unlocks after lesson completion. Pulls vocabulary only from completed objects — never introduces new language. Daily cap (5 minutes or fixed rounds). Social motivation through peer sharing, not leaderboards.

Game types worth building:
- Memory Pairs — grows as more objects complete
- Speed Round — timed True/False from known vocabulary
- What Am I? — three clues, guess the object
- Listen & Rank — Bronze/Silver/Gold ordering

---

## 13. What this is not

- **Not an AI tutor** — the tool serves the teacher-student relationship, it does not substitute for it
- **Not Duolingo** — no pressure, no hearts, no timer, no streak threat; intrinsic motivation only
- **Not assessment** — correct/incorrect data stays private between student and lesson
- **Not a replacement for classroom time** — the physical lesson (mime, discussion, notebook) is primary; the app is practice and extension
