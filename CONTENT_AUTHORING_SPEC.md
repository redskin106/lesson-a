## Core Principles

### The Golden Rule
**One unambiguous correct answer.** Every exercise item must have exactly one answer that is clearly correct. If a student could reasonably argue for a different answer, the item is invalid.

### Passport Constraint
**Only use vocabulary from the Word Passport.** The answer word must match the target tier. Sentence context can use vocabulary from any tier or below. Never introduce vocabulary not in the passport — if a word is needed, add it to the passport first.

### Tier Mapping
| Tier | CEFR | Vocabulary | Sentence complexity |
|------|------|------------|-------------------|
| Bronze | Pre-A1 | Nouns + Bronze adjectives | 3–4 words |
| Silver | A1 | + Silver adjectives | 5–6 words |
| Gold | A2 receptive | + Gold adjectives | 7–8 words + because/when/but |

### Cross-Module Consistency
Reuse the same sentences across modules — it reinforces the same language in different activities. If "The pen is long and straight." appears in Put in Order, use it in Build a Sentence too.

## Module Authoring Rules

### Gap Fill
**Pattern 1 — Contrast pair** (preferred for Bronze/Silver)
> "A [object] is [adjective A]. A [object] is ___." → adjective B

Only use confirmed opposite pairs from the passport:
- big ↔ small, old ↔ new, clean ↔ dirty, full ↔ empty (Bronze)
- long ↔ short (Silver)
- soft ↔ hard, thin ↔ wide, plastic ↔ metal (Gold)

**Pattern 2 — Negation** (good for Silver)
> "A [adjective A] [object] is not ___." → adjective B

Both words should be same tier or lower. Works with any opposite pair.

**Pattern 3 — Sensory/function clause** (Gold only)
> "A [object] feels/looks ___ when you touch/use it."
> "A [object] is ___ because it is [material/reason]."

**Rules:**
- Never use object conditions (full/empty/dirty) as the answer unless universally true
- Never use a/an distinction as the key skill
- Distractors must be clearly wrong — not debatable
- Qualify nouns with familiar context to remove ambiguity ("school bag" not "bag")
- 4 options total (1 correct + 3 distractors)
- Pool of 4 items, pick 2 per session

---

### True / False
**Rules:**
- Only use shape/size/material for unambiguous statements — never conditions alone
- Qualify the noun when needed ("school bag" not just "bag")
- 2/2 true/false split — students can't guess by elimination
- Unexpected framings ("A new pen is dirty.") force real thinking
- False statements need simple corrections in passport vocabulary
- Bronze: shape/size only. Silver: condition/nature. Gold: comparison + sensory ("softer than", "feels smooth when")
- Never "it depends on the object" — statements must be universally true or false

**Tiers:**
- Bronze: "A ball is flat." (FALSE) — shape/size, no comparison
- Silver: "A broken phone is useful." (FALSE) — condition/nature
- Gold: "A metal spoon is softer than a plastic spoon." (FALSE) — comparison, Gold vocab

---

### Word Match
- Emojis must be unambiguous and not culturally specific
- No two pairs should have similar-looking emojis
- Pool of 8, pick 5 per session
- Bronze: Bronze adjectives. Silver: Silver adjectives. Gold: Gold adjectives
- Mix nouns and adjectives within each tier

---

### Memory Pairs
- Bronze: nouns — simple "It's a [noun]." sentences
- Silver: Silver adjectives — richer sentences using adjective in context
- Gold: Gold adjectives — because/when sentences
- Pool of 6, pick 3 per session, flipback 1200ms

---

### Listen & Choose
- Questions must contain enough attributes that ONLY ONE object in the passport fits
- Bronze: one attribute ("Which object can be full?")
- Silver: two attributes ("Which object is long and straight?")
- Gold: three attributes minimum ("Which object is small, metal and smooth?")
- 4 options per question
- Pool of 4, pick 2 per session

---

### Put in Order
- Only ONE correct word order possible
- Avoid sentences where tiles could form two grammatically correct orders
- Connectors (and, but, because, when) are the key progression markers
- Word count: Bronze 3–4, Silver 5–6, Gold 7–8
- Pool of 4, pick 2 per session

---

### Say It
- Pure oral reproduction — students hear the model and record themselves
- No ambiguity needed — just natural, speakable sentences
- Must be speakable in one breath
- Bronze: single words or "It's a [noun]."
- Silver: full descriptions — "The [noun] is [adj] and [adj]."
- Gold: reasoning sentences — "The [noun] is [adj] because [reason]."
- Pool of 4, pick 2 per session

---

### Picture & Word
- Bronze: emoji → word (word-to-image) — nouns only
- Silver: word → emoji (image-to-word) — nouns only
- Gold: **FLIP** — give attributes, ask for the noun ("It is small, round and flat. It is a ___.")
  - The combination of attributes must point to ONLY ONE noun
  - This avoids ambiguity of adjective cloze and reinforces Description Pyramid logic
- Pool of 6, pick 3 per session

---

### Word Scramble
- **Nouns only** — tile-based (emoji gives visual clue)
- Bronze: 3–4 letter nouns
- Silver: 4–6 letter nouns
- Gold: same pool as Silver, harder picks
- Pool of 6, pick 3 per session

---

### Spelling
- **Adjectives only** — typing exercise all tiers (no tiles)
- Bronze: 3–5 letter adjectives (big, old, new, flat, round, clean)
- Silver: 5–8 letter adjectives (short, dirty, empty, broken, square, straight)
- Gold: 5–9 letter adjectives with phonetic complexity (smooth, heavy, plastic, metal, beautiful, thin)
- Pool of 6, pick 3 per session

---

### Listen & Match
- left = right (full text, played as audio)
- Pool items are distractors for each other — make them similar
- Bronze: single words (nouns) — student hears word, finds matching written word
- Silver: short similar sentences, one word different ("A ball is round." vs "A ball is flat.")
- Gold: longer similar sentences, one word different ("The coin is hard and metal." vs "The coin is soft and metal.")
- Pool of 6 (Bronze) / 4 (Silver) / 6 (Gold), pick 4/3/4 per session

---

### Build a Sentence
- Token roles: subject, verb, object, place, time, other
- Articles (a/the) and conjunctions (and/but/because/when) → always `other`
- Reuse sentences already authored in other modules
- Bronze: 3–4 tokens. Silver: 5–6 tokens. Gold: 7–8 tokens with connectors
- Pool of 4, pick 2 per session

---

### Question Formation
- Situation gives context for WHY the question is asked
- Tokens use roles: qword, verb, subject, object, other
- Bronze: no distractors — yes/no and simple what questions (3 tokens)
- Silver: 2 distractors — colour/shape/material questions (4–5 tokens)
- Gold: 4 distractors — multi-word questions with look like/feel/use for (5–8 tokens)
- Never use vocabulary beyond the lesson passport in the tokens
- 4 items per tier, pick 2 per session

---

### Reflection Card
- Templates must always end with `{object name}` before any "with {detail}" clause
- Hint labels must be concrete: "object name" not "thing", "e.g. big" not "size"
- Bronze: "It is a {object name}." — just name the object
- Silver: "It is a {size}, {shape}, {colour} {object name}."
- Gold: "It is a {size}, {shape}, {colour} {object name} with {detail}."
- This mirrors the Description Pyramid levels exactly
- 1 item per tier (no pool — same item every session, recall from notebook)

---

### How Does It Feel
- Feeling tiles must be actual feeling/emotion words — NOT object adjectives
- ❌ old, cold, natural (not feelings)
- ✅ peaceful, cosy, warm, excited, calm, mysterious
- Bronze: 4 tiles, no because clause
- Silver: 4 tiles, no because clause
- Gold: 4 tiles, because_mode: 'typed' — student explains in a sentence
- 2 items per tier, pick 1 per session

---

### Phonics (Sound It Out)
**Phoneme splitting rules:**
- One tile per letter UNLESS it is a true digraph
- True digraphs (one tile each): sh, ch, th, ng, ai, ee, oa, ie, or, oo, ar, er, ou, oi, ue, ph, air
- Blends always split: st, cl, pl, cr, str, sm → each letter = one tile
- Silent letters: include as a tile (phone → ph, o, n, e)

**Tier progression — word complexity:**
- Bronze: simple CVC words (3 tiles) — bag, cup, key, pen
- Silver: words with digraphs (2–3 tiles) — coin, book, phone, chair
- Gold: longer words with multiple digraphs (4–7 tiles) — smooth, straight, bottle, plastic

**Audio:** Jolly Phonics files at `assets/phonemes/sound_{grapheme}.mp3`
Special cases: `sound_oo.mp3` (short oo as in book), `sound_ooo.mp3` (long oo as in moon), `sound_th.mp3` / `sound_thh.mp3` (voiced/unvoiced th)
- Pool of 4, pick 2 per session

---

### Minimal Pairs (Listen Closely)
- Target sound must have a Jolly Phonics audio file (`assets/phonemes/sound_{grapheme}.mp3`)
- All words in options must be from the passport (nouns or adjectives)
- hasTarget: true = word contains the target sound, false = does not
- Bronze: 2 options. Silver: 3 options. Gold: 4 options
- Hint text must describe HOW to make the sound (mouth/tongue position)
- 2 items per tier, pick 2 per session

---

### Description Pyramid
- Image shown throughout all levels — never hidden
- L1: object name tiles — options include distractors from same noun category
- L2: three rows — Size / Shape / Colour — each with 4 options
- L3: because it is… — word tiles from Gold passport adjectives
- Images stored at `assets/pyramid/{object}.jpg` — square crop, neutral background
- 2 items per tier, pick 1 per session

---

## Qualifying Nouns — Context Rule
When a noun could refer to multiple sizes/conditions, qualify it with a familiar context:
- ✅ "A school bag is big." (not just "A bag is big.")
- ✅ "A classroom chair is not soft." (not just "A chair is not soft.")
- Use contexts universally familiar to your students — avoid sport/region-specific qualifiers
- Good qualifiers for Bangkok classroom: school bag, classroom chair, dinner table, phone screen

---

## Avoiding Ambiguity — Checklist
Before authoring any item, ask:
1. Is there only ONE correct answer?
2. Can the answer change depending on the specific object?
3. Is the answer universally true (not "it depends")?
4. Are all distractors clearly wrong?
5. Does the item use only passport vocabulary?
6. Would a student who doesn't know English still be able to guess correctly?

If any answer is unsatisfactory, revise the item.
